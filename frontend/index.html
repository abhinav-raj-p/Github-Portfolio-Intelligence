How it works

Three steps to a shareable profile

01
Connect with GitHub

Sign in with your GitHub account. We request read-only permission to access your public repositories, commit counts, and language stats. No code is stored.

02
See your profile analysed

GitView calculates a score based on your public activity — commit frequency, language diversity, and repository descriptions. Repositories are grouped into categories using K-Means clustering so your work areas are immediately clear.

03
Get AI-written suggestions & share

Gemini reads your profile data and writes plain-English improvement suggestions. Your scored profile can then be discovered by recruiters using the Recruiter Portal — no extra setup needed.
